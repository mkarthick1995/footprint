## Eligibility
Teams of 2–4 · age 21+ · working professionals / entrepreneurs / startups only (**no students**, whole team disqualified) ·
all members based in JAPAC · one team per person · one solution under one theme · **fresh project only**.

## Mandatory technical requirements
- Use **Google AI models (Gemini / Gemma)** *or* Google agentic platforms (Agent Platform, Antigravity, AI Studio).
- **Deployed on Google Cloud via Cloud Run or Firebase.** Solutions built primarily on other clouds are not evaluated.
- A **working prototype** demonstrating the idea end-to-end — not slides or mockups.
- All materials (code, docs, deck) in **English**.

## Submission checklist (union of the Requirements page + FAQ)
- [ ] Working **deployed link** (Cloud Run / Firebase) — judges must be able to open and use it
- [ ] **Public GitHub repository**
- [ ] **Demo video < 3:00** — public YouTube / Vimeo / Google Drive link
- [ ] **Deck → PDF**: problem, solution, community benefit, feasibility, scalability, chosen theme
- [ ] Theme stated: **Sustainability & Social Impact**
- [ ] Everything in English · link checked from a logged-out browser · submitted by **10-17**

## Judging (same for all themes)
| Weight | Criterion | What judges look for |
|---|---|---|
| **40 %** | Technical Merit & GenAI Implementation | GenAI is meaningful and central; functional and sound; scalable beyond prototype |
| **25 %** | Problem Alignment & Impact | Fits the theme; clear value for users / community |
| **25 %** | Innovation & Creativity | Fresh angle, differentiation; GenAI used beyond a superficial wrapper |
| **10 %** | UX & Solution Design | Intuitive, accessible; components work together smoothly |

Prizes (USD 30k pool): 10k / 7k / 5k + 2k each for **Best use of Google Cloud AI tools**, **Most Impactful**,
**Social Choice**, **Best UI/UX**. Our idea is a natural fit for *Most Impactful* and *Best UI/UX* too.
